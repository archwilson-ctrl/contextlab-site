ContextLab 主站採用 Hugo + GitHub Pages，作為穩定的內容網站。

Vercel 會保留給未來互動工具、AI Demo 與前端實驗，例如：

- AI 小工具
- Prompt 產生器
- 工程照片 Demo
- Dashboard Prototype

網域分工：

```text
contextlab.tw     -> Hugo 主站
lab.contextlab.tw -> Vercel 互動工具
api.contextlab.tw -> NAS 共用 API（規劃中）
```
